# Design System - xAI Services

## Theme & Palette
- Background: #050505 (Deep OLED Black)
- Surface / Cards: #121212 (Dark Graphite)
- Primary Color: #FFFFFF (Clean Pure White)
- Accent Color: #38BDF8 (Cyber Sky Blue)
- Neutral Muted: #94A3B8 (Muted Slate Gray)
- Border Color: #27272A (Subtle Dark Zinc)

## Typography
- Fonts: "Inter", "Geist", -apple-system, sans-serif
- Clean, high-tech, minimalist aesthetic with sharp contrast.

## Layout & Components
- Minimalist sticky navbar with xAI logo mark and "API Console" button
- Hero section with bold white headline, subtle glowing accent, and subtext
- 3-column card grid for CORE SERVICES with dark borders and subtle hover glow
- High-contrast stat block for KEY SPECIFICATIONS
- Clean terminal-style developer contact & documentation footer
- Fully responsive across mobile, tablet, and desktop screens
