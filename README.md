# xAI Landing Page — Services & Architecture

A modern, high-performance Next.js landing page built for xAI Services & Architecture, adhering to the design system specifications in `DESIGN.md` and content from `content.txt`.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS (Custom OLED Dark Theme)
- **Icons:** Lucide React
- **Typography:** Inter & Geist font families
- **Language:** TypeScript

## Design System Specifications
- **Background:** `#050505` (Deep OLED Black)
- **Surface / Cards:** `#121212` (Dark Graphite)
- **Primary Color:** `#FFFFFF` (Clean Pure White)
- **Accent Color:** `#38BDF8` (Cyber Sky Blue)
- **Neutral Muted:** `#94A3B8` (Muted Slate Gray)
- **Border Color:** `#27272A` (Subtle Dark Zinc)

## Sections Included
1. **Sticky Navbar:** Minimalist header with xAI logo mark, navigation links, and "API Console" action button.
2. **Hero Section:** Bold headline with glowing cyber sky blue accent pill, live network indicator, and subtext.
3. **About xAI:** Mission overview and architectural data flow visualizer.
4. **Core Services:** 3-column card grid covering:
   - Grok Intelligence
   - xAI Developer API
   - PromptIDE & Compute
5. **Key Specifications:** High-contrast statistics block covering:
   - 100K+ GPU Colossus Supercomputer Infrastructure
   - Real-Time Live Global Data Integration
   - 99.9% API Reliability & Low-Latency Responses
6. **Developer Access & Resources:** Terminal-style CLI window with interactive curl snippet and direct endpoints for API Console, Documentation, and Support.
7. **Footer:** Terminal-style developer contact & documentation footer with operational health indicator.

## Running Locally

To run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to preview the site.
